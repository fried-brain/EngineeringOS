# Curriculum Framework

Stages: orientation; foundations; guided practice; independent implementation; engineering quality; capstone; professional judgment.

Assessment combines knowledge checks, practical artefacts, tests, reproducibility, design/code review, trade-off explanation, capstone demonstration and reflection. Scores are formative and must cite submitted evidence.

Project ladder: micro-exercise → guided lab → independent build → integration project → capstone.

Integrative capstones: secure SaaS with CI/CD; grounded LLM assistant with retrieval and evaluation; robotics simulation with perception and control; game vertical slice; governed data platform; digital twin with sensors, simulation and 3D visualization.
